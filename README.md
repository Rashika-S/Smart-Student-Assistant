# Smart Student Assistant

## Problem
Students often struggle with decision-making during exams, stress, and time management.

## Solution
This project is a simple AI-based assistant that gives context-aware suggestions based on user input.

## Features
- Handles exam preparation queries
- Helps manage stress
- Provides time management advice
- Lightweight and fast

## Tech Stack
- Python
- Flask
- Google Cloud Run

## How it Works
The assistant analyzes user input using keyword-based logic and returns relevant suggestions.
